CCT PAGE — REACT + TYPESCRIPT + VITE
====================================

ESTA ES LA UNICA CARPETA DEL PROYECTO.
No vuelvas a ejecutar git clone dentro de CCT-PAGE.

PARA RETOMAR EL PROYECTO
------------------------
1. Abre CMD o PowerShell.
2. Entra a tu carpeta CCT-PAGE.
3. Ejecuta:

   git pull
   npm run dev

4. Abre la direccion Local que muestra Vite (normalmente http://localhost:5173/).

PRIMERA VEZ EN UNA PC NUEVA
---------------------------
   npm install
   npm run dev

Tambien puedes hacer doble clic en INICIAR_CCT.bat. Si node_modules no existe,
el archivo instala las dependencias y luego inicia Vite.

FUENTES ACTIVAS DEL FRONTEND
----------------------------
- src/: React + TypeScript.
- styles.css: estilo visual base.
- site.js: navegacion y comportamiento general.
- career.js: Conoce tu carrera.
- calendar.js: calendario de Inicio.
- nosotros.js: seccion Nosotros.
- formation.js: hero Academia CCT + certificaciones.
- src/features/formation/openCourse.ts: tarjetas Open Course (React/TypeScript).
- course.html / course.css / course.js: aula de Open Course.
- assets/: imagenes, logos y videos.

IMPORTANTE
----------
Los antiguos archivos v2, v3, v4, v5 y v6 fueron retirados del runtime para
que una version antigua no vuelva a pisar un cambio nuevo.

No crees archivos final.js, final2.js o nuevas variantes numeradas. Modifica la
fuente estable de la seccion correspondiente.
