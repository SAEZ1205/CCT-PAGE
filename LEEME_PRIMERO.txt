CCT PAGE — REACT + TYPESCRIPT + VITE
====================================

ESTA ES LA UNICA CARPETA DEL PROYECTO.
No vuelvas a ejecutar git clone dentro de CCT-PAGE.

PARA RETOMAR EL PROYECTO
------------------------
1. Abre CMD o PowerShell.
2. Entra a tu carpeta CCT-PAGE.
3. Ejecuta:

   git pull
   npm run dev

4. Abre la direccion Local que muestra Vite (normalmente http://localhost:5173/).

PRIMERA VEZ EN UNA PC NUEVA
---------------------------
   npm install
   npm run dev

Tambien puedes hacer doble clic en INICIAR_CCT.bat.

FUENTES ACTIVAS DEL FRONTEND
----------------------------
- src/: React + TypeScript.
- styles.css: estilo visual base historico.
- site.js: navegacion y comportamiento global.
- career.js: Conoce tu carrera de Inicio.
- calendar.js: calendario general de Inicio.
- src/features/nosotros/nosotros.ts: Nosotros.
- src/features/formation/formation.ts: Formacion + Academias.
- src/features/formation/openCourse.ts: Open Course.
- src/features/community/community.ts: Comunidad.
- src/features/events/events.ts: Eventos.
- src/styles/sections/: CSS canonico de cada seccion moderna.
- course.html / course.css / course.js: aula de Open Course.
- assets/: imagenes, logos y videos.

YA NO SE USAN
-------------
- nosotros.js
- formation.js
- community.js
- events.js
- compat-fixes.css
- archivos de imagen .b64
- archivos v2, v3, v4, v5, v6, final, final2, etc.

REGLA
-----
Una seccion tiene un solo dueño. Para editar una imagen, texto o animacion se
modifica la feature TypeScript y/o el CSS de esa seccion; no se crea otro script
que vuelva a modificar el mismo bloque despues.

El snapshot de src/legacy/snapshot.html permanece temporalmente como markup base
para conservar el frontend aprobado. No ejecuta logica ni pisa las features.

VERIFICACION
------------
Antes de considerar estable un cambio grande:

   npm run build

GitHub Actions ejecuta esta misma comprobacion en los pull requests y en main.
