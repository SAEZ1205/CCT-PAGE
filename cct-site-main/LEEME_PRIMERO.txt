CCT PAGE — VERSION COMPLETA
===========================

INICIO RAPIDO EN WINDOWS

1. Descomprime todo el ZIP en una carpeta.
2. Haz doble clic en INICIAR_CCT.bat.
3. La pagina se abrira automaticamente en http://localhost:5500.
4. No cierres la ventana negra mientras estes revisando la web.

El iniciador solo necesita Node.js y no instala dependencias. Tambien puedes abrir
index.html directamente, aunque el servidor local es la opcion recomendada.

ARCHIVOS PRINCIPALES

- index.html: sitio completo y todas sus secciones.
- styles.css: estilos y adaptacion para celular.
- script.js: navegacion, calendarios, carruseles y recursos.
- course.html / course.css / course.js: aulas y modulos de Open Course.
- assets/: imagenes, logotipos, mascota, fotos y videos locales.

RECURSOS ACADEMICOS

La seccion Recursos se navega dentro de la web. El SharePoint externo solo se
abre cuando el usuario selecciona un curso. Cada tarjeta construye la ruta de
su propia carpeta (ciclo + codigo y nombre del curso); nunca reutiliza el enlace
del Drive general. Si SharePoint cambia el nombre de una carpeta, actualiza la
propiedad folder de ese curso en script.js.
