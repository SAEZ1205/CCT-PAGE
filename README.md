# CCT-PAGE

Web del Centro Cultural de Telecomunicaciones (CCT-UNI).

## Stack
- React 18
- TypeScript
- Vite
- Tailwind CSS

## Estructura principal
La raíz del repositorio ES el proyecto. No hay otra copia de CCT-PAGE dentro de una subcarpeta.

```text
CCT-PAGE/
├─ assets/
├─ src/
├─ package.json
├─ index.html
├─ vite.config.ts
├─ tailwind.config.cjs
├─ styles.css
└─ scripts visuales de compatibilidad
```

## Desarrollo local
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

La salida se genera en `dist/`.
